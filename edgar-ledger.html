Build a watchlist with an AI

Any AI assistant (Claude, ChatGPT, Gemini, …) can turn a plain list of companies into the investments.json format this ledger reads. It takes one message:

1
Copy the prompt below — use the Copy button on the green bar.
2
Paste it into your AI chat, but don't send it yet.
3
Paste your own list directly underneath the prompt — company names, tickers, categories, dates you spotted them… any format works, even messy notes.
4
Send it. The AI replies with JSON. Save the reply as a file ending in .json (e.g. investments.json). The file must start with { — if the AI wrapped its reply in ``` fences, delete those lines.
5
Switch to the Ledger tab and load the file.
Prompt — copy this, then paste your list after it 
You are converting my investment watchlist into a JSON file for the EDGAR Ledger dashboard.

Take the list I paste below this prompt (company names, tickers, notes — any format) and return ONE JSON object in exactly this shape:

{
  "investments": [
    {
      "company": "Micron Technology",
      "category": "RAM",
      "ticker": "MU",
      "exchange": "NASDAQ",
      "country": "United States",
      "date_spotted": "01/02/2026"
    }
  ]
}

Rules:
1. Every entry must have all six keys — "company", "category", "ticker", "exchange", "country", "date_spotted" — and every value must be a string. Do not add extra keys.
2. "company": the full common name (e.g. "Advanced Micro Devices", not "AMD Inc.").
3. "ticker": the primary ticker, upper case. Prefer the US listing (NASDAQ / NYSE / OTC) when one exists — the dashboard uses this ticker to look up SEC filings. For indices, commodities, FX or crypto use a short symbol (e.g. "XAUUSD", "BTC").
4. "exchange": the exchange that ticker trades on — "NASDAQ", "NYSE", "OTC", "LSE", "XETRA", "Euronext Paris", etc. Use "NONE" for anything that is not an exchange-listed company (indices, commodities, FX, crypto).
5. "category": a short grouping label such as "Chips", "Software", "Energy". Keep any categories I give you; otherwise choose sensible ones. Entries in the same category must sit next to each other in the array.
6. "country": the company's home country, or "NONE" where it does not apply.
7. "date_spotted": MM/DD/YYYY if I gave a date for that entry, otherwise the string "NONE".
8. If you are unsure about a ticker or exchange, make your best guess — never leave a field empty.
9. Reply with the JSON only — no explanations and no markdown code fences — so I can save your reply directly as investments.json.
